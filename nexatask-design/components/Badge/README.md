Status pill for orders, payments, laundry and reservation states. Always background + text from the same status family plus a small solid dot — never colour alone, so the state still reads for a colour-blind viewer or in a black-and-white export. Use `success` for a completed/paid state, `warning` for anything in progress or partially paid, `danger` for failed or urgent, `info` for a freshly created record, `neutral` for a closed-but-not-final state like Refunded. Keep the label a short noun or noun phrase ("Paid 100%", "Courier On the Way"), never a full sentence, and never wrap to a second line.
