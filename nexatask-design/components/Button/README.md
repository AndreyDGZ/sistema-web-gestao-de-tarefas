Buttons for every action a person takes on a booking, room, order or note. Primary is `action-primary-bg` and appears once per view for the single most important action ("Add New Note", "Submit"); secondary uses `surface-card` with a `border-subtle` outline for reversible or navigational actions ("Go Back", "Next Step"); ghost is text-only for low-emphasis actions inside a dense table row; danger sits on `status-danger-bg` for destructive confirmation only, never as a first click; accent (`brand-accent`) is reserved for one hero action per screen, such as "Add New Car" on an otherwise plain list header.

Provide: a label, an optional leading or trailing chevron (`‹`/`›`) that always points in the direction of navigation, and an optional `disabled` state. Do / don't: do keep one primary button visible per screen; don't stack two accent or two primary buttons side by side; don't put a chevron on a destructive action.
