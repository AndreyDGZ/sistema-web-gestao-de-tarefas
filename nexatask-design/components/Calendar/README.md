Month grid for reservations, check-ins and adventure bookings. Today's date is a solid `ink`-filled circle with `ink-on-dark` text; a reservation spanning days renders as a rounded chip in one of `accent-violet`, `accent-amber` or `accent-teal` (rotate categories by service type or guest, not by random assignment, so the same guest keeps the same colour across the month), showing the guest name in `body-sm`-weight bold and the room/service on a lighter second line. A conflict or same-day alert (e.g. overlapping guests) uses `status-danger-bg` instead of an accent colour so it visually interrupts the pattern. On mobile the month grid becomes a scrollable agenda list — day, date badge, and its chips stacked — since a 7-column grid does not fit a phone width without shrinking chips below legible size.
