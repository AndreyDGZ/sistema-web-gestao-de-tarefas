Text field for every form across bookings, rooms, guides and settings. Provide a label (mark required fields with an asterisk in `status-danger-ink`), a placeholder, an optional helper/info message below, and a value. States: `default` (`border-subtle`), `hover` (`border-strong`), `focus` (solid `focus-ring` outline, 2px offset), `filled` (a value present, background steps to `surface-card-hover` so a completed field is scannable at a glance), `disabled`/inactive (`surface-input-disabled`, `ink-tertiary` text, no border emphasis), `error` (`status-danger-ink` border and helper text, background stays neutral). The same shell hosts a dropdown (trailing chevron), a number field (a fixed leading unit such as a phone country code) and a text area (adds a bottom-right character counter) — only the content inside `.box` changes.
