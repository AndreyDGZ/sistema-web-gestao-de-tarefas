The primary navigation, fixed to `surface-sidebar` at 280px wide (72px collapsed, icon-only). Provide an icon (18–24px, outline), a label, and mark exactly one item `active` at a time using `brand-accent` fill with `brand-accent-ink` text/icon — this is the single largest use of the accent colour on screen, so no other element on the same view should also carry a solid accent fill. Default items sit in `ink-on-dark-secondary`; hovering brightens the label to `ink-on-dark` without adding a background, keeping the active item the only filled row. Collapsed state keeps the same active treatment but drops the label; reveal it in a tooltip on hover/focus, never by auto-expanding the rail. On mobile this component is replaced by a bottom tab bar or a full-height drawer (see the README's Responsive & mobile section) rather than shown at 72px.
